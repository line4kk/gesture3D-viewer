# Gesture3D Viewer

Gesture3D Viewer - desktop-приложение для управления 3D-сценой с помощью жестов рук, считываемых с веб-камеры.

Проект состоит из Python-backend и JavaFX-frontend. Backend получает изображение с камеры, распознает руки через MediaPipe/OpenCV, определяет пользовательские жесты и отправляет события через ZeroMQ. Frontend принимает эти события и применяет их к 3D-сцене: вращает объект, двигает камеру, меняет масштаб, сохраняет скриншоты и выполняет служебные действия.

## Идея проекта

Пользователь управляет 3D-моделью с помощью естественных движений руки перед камерой: открытая ладонь отвечает за вращение и сдвиг камеры, жест L управляет вращением вокруг оси Z, а двухручные жесты позволяют приблизить сцену, сбросить вид и сохранить скриншот.

## Статус проекта

Проект находится в релизе, альфа-версия.

Основной функционал уже реализован и собран в рабочую конфигурацию, но проект нужно полноценно тестить на разных веб-камерах, условиях освещения и сценариях использования.

Сейчас можно считать, что:

- основной функционал готов;
- все ключевые механики реализованы;
- интерфейс и связка backend/frontend работают;
- дальше нужна в первую очередь проверка и стабилизация.

## Доступные жесты

На текущем этапе жесты распознаются по позе руки и движению ключевых точек MediaPipe.

| Жест | Действие в приложении | Событие |
| --- | --- | --- |
| Одна открытая ладонь, движение руки вверх/вниз/влево/вправо | Вращение модели вокруг осей X/Y | `rotate` |
| Одна рука в форме буквы L, движение руки влево/вправо | Вращение модели вокруг оси Z | `rotate_z` |
| Две открытые ладони, движение обеих рук в одном направлении | Перемещение камеры по сцене | `camera_pan` |
| Две открытые ладони, разведение или сведение рук | Приближение или отдаление камеры | `camera_scale` |
| Две руки в жесте "Here", удержание примерно секунду | Сброс положения камеры | `reset_view` |
| Две руки в жесте "Camera", удержание примерно секунду | Сохранение скриншота сцены | `screenshot` |

Приоритет жестов задается в backend: если несколько детекторов потенциально подходят под текущий кадр, обработчик выбирает первый распознанный жест по порядку подключения detector-классов.

## Запуск

Сейчас frontend автоматически запускает backend как отдельный процесс. Поэтому обычный сценарий запуска - стартовать JavaFX-приложение, а backend поднимется сам.

### Frontend

Из корня репозитория:

```powershell
cd frontend\gesture3DViewer
.\mvnw.cmd javafx:run
```

### Backend

Если нужен ручной запуск backend для отладки:

```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m src.main
```

Backend по умолчанию работает с камерой, выбранной из frontend. Если выбора не было, используется камера по умолчанию, а события публикуются в ZeroMQ для frontend.

## Ручное управление

В JavaFX viewer есть ручное управление для отладки без жестов:

- `W` / `S` - вращение модели вокруг X;
- `A` / `D` - вращение модели вокруг Y;
- `Q` / `E` - вращение модели вокруг Z;
- `G` / `J` - смещение камеры по горизонтали;
- `Y` / `H` - смещение камеры по вертикали;
- колесо мыши - изменение масштаба;
- `Backspace` - сброс вида.

## Основные файлы

- `backend/src/main.py` - точка входа backend.
- `backend/src/senders.py` - отправка gesture-событий, статистики и видео через ZeroMQ.
- `backend/src/gesture_handler.py` - выбор активного детектора жестов.
- `backend/src/gesture_detectors/*` - detector-классы для отдельных жестов.
- `backend/src/gesture_recognizing/gesture_recognizers.py` - проверка составных поз рук.
- `frontend/gesture3DViewer/src/main/java/com/line4kk/gesture3dviewer/Application.java` - точка входа JavaFX-приложения.
- `frontend/gesture3DViewer/src/main/java/com/line4kk/gesture3dviewer/BackendProcess.java` - запуск backend из frontend.
- `frontend/gesture3DViewer/src/main/java/com/line4kk/gesture3dviewer/SceneController.java` - управление 3D-сценой, проектами и настройками.
- `frontend/gesture3DViewer/src/main/java/com/line4kk/gesture3dviewer/ui/ScreenshotManager.java` - сохранение скриншотов.
- `frontend/gesture3DViewer/src/main/java/com/line4kk/gesture3dviewer/ui/ViewerProject.java` - работа с проектами.
